# 需求文档:AI 陪学助理(第一期,v0.5.0)

> 状态:已确认(2026-09-24 森哥确认开工)
> 日期:2026-09-24
> 关联:七关流程第一关产物;计划见 PLAN-v0.5.0-ai-assistant.md

## 1. 背景与愿景

番茄钟已具备完整的目标管理体系(目标→科目→计划→任务 + 打卡/统计/预测),当前定位是"工具"。用户的终极愿景是**懒人化**:用户可以继续手动管理,也可以把管理交给 AI——AI 通过引导式对话理解用户的学习目标、可用时间、考试安排,然后**一次性配好整套目标/计划/安排**,并在日常使用中持续分析学习情况、给出调整建议。

产品形态:番茄钟从"工具"升级为"陪学助理"。核心原则:**AI 给方案,用户点头才生效;不配 API 密钥,应用与现在完全一样**。

## 2. 分期总览

| 期 | 版本 | 内容 | 状态 |
|---|------|------|------|
| 第一期 | v0.5.0 | AI 配置 + 助手对话面板 + 每日学习分析 + 今日学习顺序建议(**全部只读**) | 本期 |
| 第二期 | v0.5.x | 引导式建档:AI 访谈(考什么/几号考/每天时长/科目)→ 生成完整方案预览 → 用户确认一键写入 | 规划 |

"今天什么时间学什么科目"采用**顺序建议**(不绑具体时刻);真正的时刻表日程视第一期使用反馈再议。

## 3. 第一期详细需求(v0.5.0)

### F1 AI 设置(前置)
- 设置面板新增「AI 助手」区:DeepSeek API 密钥输入(可粘贴/清除/显示隐藏)、模型选择(deepseek-chat / deepseek-reasoner)、连接测试按钮
- 密钥存储:本地数据文件(`%APPDATA%/pomodoro/data.json`),**绝不进代码仓库**(数据文件本就在仓库外)
- 未配置密钥时:不显示 AI 助手入口,应用所有现有行为零变化

### F2 AI 助手面板(对话)
- 主界面顶栏新增 AI 助手图标,点开对话面板(与现有弹窗面板体系一致)
- 支持多轮对话;对话历史仅保留当次会话(重启清空,第一期不做历史存储)
- AI 回复基于真实数据回答(见 F3 数据摘要),不允许编造不存在的数据

### F3 每日学习分析(核心功能)
- 面板内一键「今日复盘」:AI 基于当日+近 7 天真实数据生成分析
- 分析内容:今日完成情况(时长/番茄数/各科目分布)、与最近趋势对比、计划完成度点评、明日学习建议(顺序建议,见 F4)
- 生成过程有加载状态;网络失败给友好错误与重试,不影响应用其他功能

### F4 今日学习顺序建议
- AI 结合今日各计划应学时长、各科目近期投入、用户当日偏好,给出"今天建议:先学 X(约 N 分钟),再学 Y…"形式的顺序建议(不绑具体时刻)
- 建议展示在对话中;用户可追问调整("今天只有 1 小时,重新排")

### 附带修复(随版本带上)
- **幽灵计划**(v0.4.2 审核发现):恢复目标时,其名下科目中被单独归档的计划不恢复导致永久隐藏——修复为恢复目标时一并恢复名下计划的归档状态

## 4. 验收标准(不超诉求范围)

1. 不配密钥:无 AI 助手入口、无任何自动 AI 网络请求,现有计时/任务/统计/通知行为与 v0.4.2 完全一致(设置面板新增的 AI 配置区与幽灵计划修复属本版功能/修复项,不在此限)
2. 配置密钥:连接测试通过;可切换模型并立即生效
3. 今日复盘:分析中的时长/数量/科目分布与「数据统计」面板一致(引用真实数据,抽查 3 项核对)
4. 顺序建议:基于当日真实计划生成,格式为顺序+建议时长,不含具体时刻
5. AI 对话:可多轮;问"我今天学了多久"能答对(与统计面板一致)
6. 网络断开:AI 功能给错误提示,应用其他功能不受任何影响
7. 密钥安全:代码仓库(`git ls-files`)中无密钥字符串;密钥只存在于本地数据文件
8. 测试全绿(现有 190 基线不破坏,新增功能的纯逻辑部分有测试);主进程改动走代码审核
9. 幽灵计划:按「单独归档科目→归档目标→恢复目标」序列操作后,计划恢复可见

## 5. 本期明确不做

- AI 写入/修改任何用户数据(目标/计划/任务)——全部留给第二期
- 对话历史持久化、多会话管理
- 时刻表式日程(19:00-20:00 学 XX)
- DeepSeek 以外的模型供应商
- 声音/白噪音/云同步等既有「暂不做」项不变

## 6. 技术要点(供计划关参考)

- API 调用在**主进程**(Node.js fetch),渲染层经 preload 桥调用(规避 CORS 与密钥暴露到渲染层)
- DeepSeek API 为 OpenAI 兼容接口;第一期仅用 chat completion,不用 function calling(无写入场景)
- 数据摘要模板:当日统计 + 近 7 天趋势 + 各计划进度,拼入 system prompt;回复要求中文
- UI 遵循现有三层分离:对话面板组件进 components/,AI 请求逻辑进主进程,提示词组装等纯函数进 features/(可单测)
- 密钥字段进 data.json 需评估是否加 schema 迁移(v10:settings.aiConfig)
